# СПРОСИ-ИИ ВЗАИМОДЕЙСТВИЕ МОДУЛЕЙ - ДЕТАЛЬНЫЙ ПСЕВДОКОД ДЛЯ MERMAID ДИАГРАММЫ

## ОБЗОР
Данный документ содержит детальный псевдокод для создания комплексной Mermaid диаграммы,
показывающей взаимодействие модулей/файлов в приложении СпросиИИ (AskII). Диаграмма иллюстрирует
поток данных, зависимости и паттерны коммуникации между различными слоями с акцентом на
локальную реализацию ИИ через Ollama.

## ДЕТАЛЬНЫЕ ОПИСАНИЯ ПОТОКОВ

### 1. ПОТОК СОЗДАНИЯ НОВОГО ВОПРОСА
```
Действие пользователя: Задать новый вопрос
├── composeNewQuestionForm.js
│   ├── Валидирует ввод вопроса
│   ├── Выбирает ИИ модель (локальную/внешнюю)
│   ├── Выбирает категорию
│   └── Вызывает действие хранилища
├── questions.js (Хранилище состояния)
│   ├── Отправляет API запрос
│   └── Обновляет локальное состояние
├── QuestionsController.rb
│   ├── Валидирует параметры
│   ├── Проверяет разрешения
│   └── Вызывает бизнес-логику
├── QuestionBuilder.rb
│   ├── Проверяет дубликаты
│   ├── Создает новый вопрос
│   ├── Устанавливает начальный статус
│   └── Применяет бизнес-правила
├── Question.rb (Модель)
│   ├── Валидирует данные
│   ├── Сохраняет в базу данных
│   └── Запускает колбэки
├── QuestionProcessingJob.rb (Фоновая задача)
│   ├── Ставит в очередь для обработки ИИ
│   └── Отправляет в соответствующий ИИ сервис
└── QuestionChannel.rb (WebSocket)
    ├── Уведомляет пользователя об обработке
    └── Обновляет UI со статусом
```

### 2. ПОТОК ГЕНЕРАЦИИ ОТВЕТА ЛОКАЛЬНОГО ИИ
```
Системное действие: Генерация ответа ИИ через Ollama
├── QuestionProcessingJob.rb
│   ├── Извлекает вопрос из очереди
│   ├── Определяет лучшую ИИ модель
│   └── Подготавливает контекст
├── AiRouterService.rb
│   ├── Проверяет доступность локальных моделей
│   ├── Балансирует нагрузку
│   ├── Выбирает Ollama если доступно
│   └── Fallback на внешние API при необходимости
├── LocalAiService.rb (Локальный ИИ)
│   ├── Проверяет статус Ollama сервера
│   ├── Валидирует ollama-key
│   ├── Загружает модель если не загружена
│   ├── Вызывает Ollama API
│   ├── Обрабатывает ответ Qwen2.5:14b
│   └── Мониторит использование ресурсов
├── AnswerBuilder.rb
│   ├── Создает объект ответа
│   ├── Применяет подсветку кода
│   ├── Валидирует содержимое
│   └── Устанавливает метрики качества
├── Answer.rb (Модель)
│   ├── Сохраняет данные ответа
│   ├── Связывает с вопросом
│   └── Обновляет статус вопроса
├── LocalAiModel.rb (Модель)
│   ├── Обновляет статистику использования
│   ├── Логирует производительность
│   └── Отслеживает использование ресурсов
├── AnswerProcessingJob.rb (Фоновая задача)
```

## ПАТТЕРНЫ ВЗАИМОДЕЙСТВИЯ КОМПОНЕНТОВ

### Поток состояния фронтенда
```
JS Компонент → Действие хранилища состояния → API вызов → Мутация хранилища → Обновление компонента
```

### Поток обработки бэкенда
```
Контроллер → Сервис/Строитель → Модель → Задача → WebSocket → Обновление фронтенда
```

### Поток обработки локального ИИ
```
Вопрос → ИИ сервис → Ollama API → Обработка ответа → Уведомление пользователя
```

### Поток обновления в реальном времени
```
Изменение модели → Триггер задачи → WebSocket трансляция → Мутация хранилища → Обновление UI
```
